# Security Policy

**Status: pre-alpha; no cleanup software is currently released.**

File cleanup is inherently destructive. Please do not run experimental implementations against irreplaceable files or active agent workspaces.

For security disclosures, prefer GitHub private vulnerability reporting if it is enabled for this repo. If it is not available, contact the maintainer privately to arrange a non-public report. Do not put exploits, credentials or personal machine paths in public issues.

Security areas include task identity and ownership, lease integrity, symlink/path traversal, TOCTOU races, data retention, unexpected mounts, safe notifications and accurate disk accounting.

**Task completion alone never authorizes deletion.**
